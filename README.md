# 1-5+31IV (1-5731N)

*Lift the stone…* — an installable web app (PWA) port of the free logic game **Einstein Puzzle** 2.0
(Flowix Games, © 2003-2005 Alexander Babichev, GPL v2+). The name reads "1-STEIN": the 1 is the German *ein*, and a stone is waiting to be lifted. The title is written with the game's own symbols (digits, signs, Roman numerals), hence "1-5+31IV".

Six rows of six symbols, six columns: use the clues to find which symbol goes in each cell. Every puzzle is generated and can be solved by pure deduction.

- Every puzzle has a code (`01-AAAA-AAAA`, shown under the timer): the same code always gives the same puzzle, so you can replay or share one. A **puzzle of the day** is the same for everyone on the same date.
- Playable with the keyboard and with a screen reader (arrow keys, Enter, 1-6, M, U, T, Esc: see the Help screen).
- 20 languages (English by default), 4 themes × light/dark, sounds of the original, works offline, no account, no tracking.
- Statistics are kept on the device; they can be exported to / imported from a `.json` file.

> The translations (except French and English) were written with an AI and have **not** been proofread by native speakers. **Native speakers wanted**: see [TRANSLATIONS.md](TRANSLATIONS.md) for the list and how to help (no coding needed: in the game, **Help → "A mistake in a translation?"** opens a ready-made form).

## Install / play

Open **https://tiberius-claudius-drusus.github.io/1-5731N/** on your phone or computer and use "Install app" (Android/Chrome, desktop) or "Add to Home Screen" (iOS Safari). It works offline once loaded.

## Run it locally

For local tests only (`python3 -m http.server` has no HTTPS and sends no security headers; use any static host with HTTPS for real use). A service worker needs a secure origin; `localhost` counts as one:

```bash
python3 -m http.server 8080      # then open http://localhost:8080
```

On a phone: open the page in the browser, then "Add to Home Screen" (iOS: Safari → Share → *Add to Home Screen*).

## Files

- `engine.js` — generator, solver and rules, ported from `puzgen.cpp` / `rules.cpp` (test: `node test_engine.js`).
- `test_code.js` — puzzle codes (same code = same puzzle, pinned puzzles, puzzle of the day; `STEIN_HEAVY=1` for the large samples). `test_version.js` — release check (app version = cache name = changelog). The tests run on every push (`.github/workflows/test.yml`).
- `app.js`, `index.html` — interface; game saved in `localStorage` (keys `stein.*`). The CSS is inlined in `index.html`.
- `glyphs.js` — the 36 game symbols and the title characters, drawn as SVG.
- `themes.js`, `THEMES.md` — themes (how to add one).
- `library.js`, `lib_base.js`, `worker.js`, `addons/` — levels and puzzle packs. `engine.js` grades a puzzle (`gradeSolve`: a systematic player's deduction, easiest clue first) and turns the score into a note 0-20 and one of five levels (easy, normal, hard, expert, extreme = the top 0.5 %). `lib_base.js` is the base pack (2 500 puzzle codes, 500 per level); the puzzle of the day is a puzzle of a level drawn from the date. A pack is a JSON list of codes (`{format, id, name, gen, scale, puzzles: [[code, score], ...]}`): the game rebuilds each puzzle from its code and recomputes the level, so the level shown in the game is always the real one; the score written in a pack only decides where a puzzle is listed, and a puzzle that does not match the level asked for is dropped when it is picked; a pack made for another generator or scale is refused. Add-ons are put in `addons/` (listed in `addons/index.json`) or installed from a file in Options. While a game is on screen, `worker.js` makes one puzzle every 10 s and keeps it for its level. Tools: `tools/grade_distribution.js` (distribution of the scores), `tools/make_pack.js` (base library and add-on packs). Test: `node test_library.js`.
- `TRANSLATIONS.md`, `.github/ISSUE_TEMPLATE/translation.yml` — proofreading status of the languages and the correction form.
- `i18n.js`, `lang/<code>.js` — texts; `node test_lang.js` checks that every language has the same keys, `{placeholders}` and tags as French. `tools/gen_lang.py` is the initial authoring aid; the `lang/*.js` files are the source.
- `logo.js`, `icon-*.png` — logo (point cloud) and icons, generated by `tools/logo/` (`pebble.py` → `build_data.py` / `icon.py`; needs `numpy scipy pillow`).
- `snd/` — sounds of the original game.
- `sw.js`, `manifest.webmanifest` — offline cache and installability.

## Help translate / proofread

Eighteen of the twenty languages have never been read by a native speaker, and a game is only as good as its words. If you speak one of them (Hindi, Arabic, Korean, Turkish, Japanese, Portuguese and Latin are the least certain), a few minutes are enough: open the game, go to **Help**, tap **"A mistake in a translation?"** and tell us which text should say what. You do not need to know GitHub or code. Details, the language table and the pull-request route: [TRANSLATIONS.md](TRANSLATIONS.md). *Aide en français dans le même fichier.*
