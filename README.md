# 1-5+31IV (1-5731N)

*Lift the stone…* — an installable web app (PWA) port of the free logic game **Einstein Puzzle** 2.0
(Flowix Games, © 2003-2005 Alexander Babichev, GPL v2+). The name reads "1-STEIN": the 1 is the German *ein*, and a stone is waiting to be lifted. The title is written with the game's own symbols (digits, signs, Roman numerals), hence "1-5+31IV".

Six rows of six symbols, six columns: use the clues to find which symbol goes in each cell. Every puzzle is generated and can be solved by pure deduction.

- 20 languages (English by default), 4 themes × light/dark, sounds of the original, works offline, no account, no tracking.
- Statistics are kept on the device; they can be exported to / imported from a `.json` file.

> The translations (except French and English) were written with an AI and have **not** been proofread by native speakers. Corrections are welcome.

## Run it

Serve the folder over HTTPS (a service worker needs a secure origin; `localhost` also works):

```bash
python3 -m http.server 8080      # then open http://localhost:8080
```

On a phone: open the page in the browser, then "Add to Home Screen" (iOS: Safari → Share → *Add to Home Screen*).

## Files

- `engine.js` — generator, solver and rules, ported from `puzgen.cpp` / `rules.cpp` (test: `node test_engine.js`).
- `test_version.js` — release check (app version = cache name = changelog); the three tests run on every push (`.github/workflows/test.yml`).
- `app.js`, `index.html` — interface; game saved in `localStorage` (keys `stein.*`). The CSS is inlined in `index.html`.
- `glyphs.js` — the 36 game symbols and the title characters, drawn as SVG.
- `themes.js`, `THEMES.md` — themes (how to add one).
- `i18n.js`, `lang/<code>.js` — texts; `node test_lang.js` checks that every language has the same keys, `{placeholders}` and tags as French. `tools/gen_lang.py` is the initial authoring aid; the `lang/*.js` files are the source.
- `logo.js`, `icon-*.png` — logo (point cloud) and icons, generated by `tools/logo/` (`pebble.py` → `build_data.py` / `icon.py`; needs `numpy scipy pillow`).
- `snd/` — sounds of the original game.
- `sw.js`, `manifest.webmanifest` — offline cache and installability.
